### 3.2 数据流转测试（仅验证代码逻辑，不依赖外部服务）

#### TC-001：密码安全流转 ✅
```
输入: password="Abc12345!" → bcrypt哈希 → DB存储
验证: CheckPassword(hash, "Abc12345!") = true
      CheckPassword(hash, "WrongPass") = false
      hash ≠ 原文（不可逆）
```

#### TC-002：金额计算验证（分单位）✅
```
8卡 × 720小时 × ¥35/卡·时 = 20160000 分 (¥201,600.00)
平台佣金 5% = 20160000 × 500 / 10000 = 1008000 分 (¥10,080.00)
供给方应得 = 20160000 - 1008000 = 19152000 分 (¥191,520.00)
所有金额 int64，无浮点运算，无精度丢失
```

#### TC-003：订单状态机 ✅
```
pending_payment → paid → provisioning → active → completed
                              ↓            ↓
                          refunding → refunded
```
非法跳转（如 pending_payment → active）被 Service 层拦截。

#### TC-004：库存原子操作 ✅
```
下单: UPDATE products SET stock = stock - 8 WHERE id = 1 AND stock >= 8
超卖: stock=4, quantity=8 → 返回 "insufficient stock"（affected_rows=0）
```
