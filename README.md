# 算力撮合交易平台 + AI Token 工厂 —— 需求文档（v1 Web）

> 状态：**第一阶段 · 需求设计中（待评审）**

> 文档语言：中文。所有相对日期已转为绝对日期。当前编写日期：2026-06-30。

---

## 0. 一句话定位

一个**轻资产、无自有算力机房**的在线平台：以「算力现货挂牌撮合交易所」为核心，叠加「AI Token 工厂（独立 newapi）」「设备/机电/施工居间」「设备融资租赁（仅展示留资）」四类业务，靠撮合佣金、算力差价、Token 毛利、居间服务费盈利。

---

## 1. 关键决策记录（来自 2026-06-30 与产品负责人确认）

| # | 决策点 | 结论 | 影响 |
|---|--------|------|------|
| D1 | v1 定位 | **完整在线挂牌撮合交易所**（含在线支付） | 触发 ICP/EDI/等保三级/算法备案等全套合规，见 [第11章](docs/11-合规资质与法律风险.md) |
| D2 | 支付渠道 | **易宝支付（YeePay）**，服务商模式 + 合单支付 + 分账 | 资金不进平台自有账户，规避"二清"红线 |
| D3 | Token 工厂 | **新部署一套独立 newapi**，不复用现有 kaizo.top | 主平台做账户/订单/导流对接，计量计费在 newapi |
| D4 | 金融（融资租赁） | **独立板块，仅做介绍 + 邮件/联系方式留资**，不做系统化撮合 | 规避融资租赁牌照风险，降低 v1 工作量 |
| D5 | 角色体系 | **全角色自助多端**：买家 / 机房供给方 / 设备厂商 / 资方 + 运营总后台 | 工作量最大项，需做入驻审核与多工作台 |
| D6 | 品牌 | **暂用占位**，后续单独定名 | 官网视觉、域名、版权署名后置 |

> 决策可在评审时修订，修订后同步更新本表与对应章节。

## 4. 重大风险速览（详见第11、12章）

| 等级 | 风险 | 一句话结论 |
|------|------|-----------|
| 🔴 红线 | 虚拟货币挖矿 | 42号文穿透式监管，"云算力租赁面向公众融资"刑事风险最高、合同无效；必须结构性排除并强制识别终止 |
| 🔴 红线 | 支付二清 | 资金严禁进平台自有账户做二次清算；必须走易宝持牌账户 + 分账 |
| 🟠 高 | EDI/ICP 许可证 | 第三方入驻 + 在线撮合交易=必须办 EDI；上线交易前须取得，办理 2-6 个月 |
| 🟠 高 | 算法备案/安全评估 | Token 工厂对外提供大模型服务需网信办备案，周期 2-3 个月 |
| 🟠 高 | 等保三级 | 交易平台须过等保三级，测评+整改 2-4 个月 |
| 🟡 中 | 幽灵算力/机房资质 | 必须建机房资质审核台账，仅接合规持证 IDC |
| 🟡 中 | 开源协议合规 | newapi 等开源组件协议需逐一核查（见第12章） |

> ⚠️ **合规与上线节奏强相关**：v1 可以"先开发、后取证"，但**线上真实成交/收款必须在 EDI+等保+支付进件齐备后开闸**。建议设计「展示+撮合可先上线，交易开关受合规状态控制」的灰度策略，详见第13章。
